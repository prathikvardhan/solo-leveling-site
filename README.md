# Solo Leveling Fan Site

An unofficial fan-made static website inspired by Solo Leveling. It is not affiliated with or endorsed by the rights holders.

## Pages

- `index.html`: landing page
- `trailer.html`: official and community trailer entries
- `status.html`: Sung Jinwoo profile and status visualization
- `army.html`: shadow soldier roster
- `faq.html`: frequently asked questions
- `updates.html`: demo notification form
- `terms-privacy.html`: site terms and privacy notice

Shared styling and behavior are in `styles.css` and `script.js`.

## Run locally

From this directory, start a static server:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

The notification form is a front-end demo and does not submit or store email addresses. External images and video are provided by their respective hosts.
